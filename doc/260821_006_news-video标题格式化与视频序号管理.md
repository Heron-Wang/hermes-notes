## 背景/问题

news-video 原标题格式为 `每日{category}速递 · {date}`（如"每日科技速递 · 2026-08-18"），用户要求改为统一标题 `每日速递 · {date}-{序号}`（如"每日速递 · 2026-08-18-001"），序号表示当天生成的第几个视频。

## 修改内容

### 1. 前端标题

```html
<!-- 修改前 -->
<title>📺 每日科技速递</title>
<h1>📺 每日科技速递</h1>

<!-- 修改后 -->
<title>📺 每日新闻速递</title>
<h1>📺 每日新闻速递</h1>
```

### 2. 视频标题格式（web_server.py）

```python
# 修改前
"title": f"每日{category}速递 · {date}"

# 修改后
# 从 video_id 中提取序号
seq_str = ""
parts = video_id.split("_")
if len(parts) >= 3 and parts[0] == "news":
    seq_str = parts[2]  # 如 001
"title": (f"每日速递 · {date}-{seq_str}" if seq_str else f"每日速递 · {date}")
```

### 3. video_id 格式（pipeline.py）

```python
video_id = f"news_{date_compact}_{seq:03d}_{category}_{count}"
# 如: news_20260818_001_科技_5
```

序号计算：扫描归档目录中当天已存在的视频目录数量 +1

```python
seq = 1
if ARCHIVE_DIR.exists():
    existing = [d.name for d in ARCHIVE_DIR.iterdir()
                if d.is_dir() and d.name.startswith(f"news_{date_compact}_")]
    seq = len(existing) + 1
```

## 踩坑：dict 中不能有赋值语句

第一次修改时在 dict 字面量中直接写赋值语句导致语法错误：

```python
# ❌ 错误 - dict 中不能有赋值语句
{
    "title": f"每日{category}速递 · {date}",
    seq_str = ""  # SyntaxError!
    parts = video_id.split("_")
    ...
}

# ✅ 正确 - 用三元表达式
{
    "title": (f"每日速递 · {date}-{seq_str}" if seq_str else f"每日速递 · {date}"),
}
```

## 经验总结

1. **Python dict 字面量中只能有 `key: value` 对**，不能插入赋值语句。复杂逻辑要在 dict 外部计算
2. **序号从 video_id 提取**而非独立存储，减少状态管理复杂度
3. **video_id 命名规范**：`news_YYYYMMDD_NNN_类型_数量`，序号用零填充 3 位
