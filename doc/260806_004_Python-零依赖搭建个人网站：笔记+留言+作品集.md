## 背景：不想装框架，就想快速搭个个人站

想做一个个人网站，包含技术笔记、访客留言、作品集展示。但不想装 Django/Flask，也不想配数据库。用 Python 标准库就能搞定。

## 为什么用 Python 标准库？

- **零依赖：** 不用 pip install，`python3 server.py` 直接跑
- **够用：** 个人站流量小，stdlib 的 http.server 完全够
- **好维护：** 一个文件搞定

## 架构设计

```
heronwang.cn
├── /              首页（导航入口）
├── /notes         技术笔记（列表 + 详情）
├── /guestbook     访客留言板
├── /portfolio     作品集
├── /api/notes     API（推送笔记用）
├── /api/guestbook API（访客留言用）
└── /api/portfolio API（注册作品用）
```

前端用单页应用（SPA）风格，通过 hash 路由切换页面，不用刷新。

## 数据存储：SQLite

不用 MySQL，直接用 Python 内置的 sqlite3：

```python
import sqlite3

def init_db():
    conn = sqlite3.connect('data/site.db')
    conn.executescript('''
    CREATE TABLE IF NOT EXISTS notes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        content TEXT NOT NULL,
        tags TEXT DEFAULT '[]',
        category TEXT,
        source TEXT DEFAULT 'hermes',
        created_at TEXT NOT NULL
    );
    CREATE TABLE IF NOT EXISTS guestbook (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT, message TEXT, contact TEXT,
        ip TEXT, created_at TEXT, is_approved INTEGER DEFAULT 1
    );
    ''')
```

> **为什么用 SQLite？** 单文件、零配置、够快。个人站每天几十个请求绰绰有余。

## 敏感信息脱敏

笔记来源包括 AI 对话总结，可能包含密码 token。做了脱敏模块：

```python
PATTERNS = [
    (r'(password|passwd|密码)\s*[:=]\s*\S+', r'\1=***REDACTED***'),
    (r'(token|api_key|secret)\s*[:=]\s*\S+', r'\1=***REDACTED***'),
    (r'***REDACTED***', '***REDACTED***'),
]
```

> **双重保险：** 服务端入口也做一遍脱敏，检测到3处以上返回警告。

## 避坑提示

1. **f-string 里的 CSS 花括号要双写**：CSS 的 `{` 要写成 `{{`
2. **SQLite 并发写入限制**：高并发场景要换数据库
3. **CORS 头别忘加**：前端和 API 不在同一域名时需要
