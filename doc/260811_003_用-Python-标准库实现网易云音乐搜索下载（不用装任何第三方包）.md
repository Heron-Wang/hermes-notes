## 背景/问题

想在 NAS 上做个音乐播放服务，需要能搜索和下载歌曲。一开始试了 `musicdl` 这个 Python 包，结果它依赖一大堆东西（`nodejs-wheel-binaries` 57.9MB、`av` 33.7MB、`lingua-language-detector` 91.8MB……），下载安装又慢又占空间。

其实如果只需要搜索和下载 MP3，用 Python 标准库（`urllib` + `json`）就能搞定，总共不到 100 行代码，零依赖。

## 原因分析

网易云音乐有一个**免费的公开 API**，不需要登录、不需要 API Key：

- **搜索接口**：`https://music.163.com/api/search/get?s=关键词&type=1&limit=10`
- **下载接口**：`https://music.163.com/song/media/outer/url?id=歌曲ID.mp3`

这两个接口都是公开的，搜索返回 JSON，下载直接给 MP3 文件流。只要请求时带上 `User-Agent` 和 `Referer` 头就行（防爬虫的基本措施）。

`musicdl` 之所以那么大，是因为它支持十几个音源（YouTube、酷狗、QQ 音乐等），每个音源都有自己的解析逻辑和依赖。如果只用网易云一个源，完全不需要这些。

## 解决方案

核心代码就三个函数：搜索、获取下载链接、下载文件。

```python
import json, os, urllib.request, urllib.parse

# 网易云请求需要带这两个头，否则会被拦截
HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)",
    "Referer": "https://music.163.com",
}

def search_songs(keyword, limit=10):
    """搜索歌曲，返回列表"""
    # URL 编码中文关键词
    params = urllib.parse.urlencode({"s": keyword, "type": 1, "limit": limit})
    url = f"https://music.163.com/api/search/get?{params}"
    req = urllib.request.Request(url, headers=HEADERS)
    with urllib.request.urlopen(req, timeout=10) as resp:
        data = json.loads(resp.read())
    
    songs = []
    for s in data.get("result", {}).get("songs", []):
        artists = "/".join(a["name"] for a in s.get("artists", []))
        songs.append({
            "id": s["id"],
            "name": s["name"],
            "artist": artists,
            "album": s.get("album", {}).get("name", ""),
        })
    return songs

def get_download_url(song_id):
    """获取下载URL，用 HEAD 请求检测是否可用"""
    url = f"https://music.163.com/song/media/outer/url?id={song_id}.mp3"
    req = urllib.request.Request(url, method="HEAD", headers=HEADERS)
    try:
        resp = urllib.request.urlopen(req, timeout=5)
        if resp.status == 200:
            return url
    except Exception:
        pass
    return None

def download_song(song, target_dir):
    """下载歌曲到指定目录"""
    dl_url = get_download_url(song["id"])
    if not dl_url:
        return None
    
    # 文件名：歌手 - 歌名.mp3，清理非法字符
    filename = f"{song['artist']} - {song['name']}.mp3"
    for ch in '<>:"\\\\|?*':
        filename = filename.replace(ch, "")
    
    filepath = os.path.join(target_dir, filename)
    if os.path.exists(filepath):
        return filepath  # 已存在不重复下载
    
    req = urllib.request.Request(dl_url, headers=HEADERS)
    with urllib.request.urlopen(req, timeout=30) as resp:
        data = resp.read()
    with open(filepath, "wb") as f:
        f.write(data)
    return filepath
```

使用方式：

```bash
# 搜索
python3 download_music.py "许嵩 半城烟沙" --list-only

# 下载第1首
python3 download_music.py "许嵩 半城烟沙" --download 1

# 批量下载前5首
python3 download_music.py "周杰伦" --download 5
```

## 避坑提示

- **免费接口提供的是试听版**：部分歌曲可能有版权限制，下载到的是试听片段（通常 30 秒），完整版需要配合其他音源
- **搜索结果有噪音**：翻唱版本会混入原版，搜索时加上歌手名能提高准确率，比如 `"许嵩 半城烟沙"` 比 `"半城烟沙"` 更精准
- **记得带 Referer 头**：不带 `Referer: https://music.163.com` 的话，API 会返回空结果
- **文件名要清理非法字符**：`< > : " \ | ? *` 在 Windows 文件系统里非法，Linux 虽然能用但会影响 Samba 共享
- **已存在的文件跳过**：加个 `os.path.exists` 检查，避免重复下载浪费带宽
- **配合 music-server 自动入库**：下载到 music-server 的 `MUSIC_DIR` 目录后，它会自动扫描新歌，不需要手动刷新
