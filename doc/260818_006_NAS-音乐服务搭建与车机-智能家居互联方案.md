## 背景/问题

NAS 上有 90+ 首音乐文件（mp3 + flac + wav），想要实现：
1. 局域网内任何设备能直接播放
2. 小爱音箱语音控制播放
3. 车机（比亚迪秦L DiLink）能听 NAS 上的歌
4. 外出时通过外网访问

## 架构设计

```
NAS 音乐文件 (/volume1/Share/Media/Music/)
  ├── music-server (:8091)     — HTTP 直链播放服务
  ├── xiaomi-bridge (:8090)    — 小爱音箱 → Hermes 桥接
  ├── xiaogpt (:8075)          — 小爱语音识别转发
  ├── DLNA (NAS 自带 dlna_serv) — 局域网设备投屏
  └── Samba (smbd)              — 文件共享
```

### 三层路由设计

用户对小爱说"播放许嵩"：
1. **音乐类指令** → xiaogpt 识别 → music-server 返回歌曲 URL → micli 播放
2. **操作类指令**（"开灯"等）→ bridge 转发到 Hermes Agent（60s timeout）
3. **聊天类指令** → bridge 转发到 CANNBOT LLM

## music-server 实现

Python 标准库 HTTP 服务器，扫描音乐目录提供直链：

```python
# 核心功能
GET /           → 列出所有歌曲 JSON
GET /play/{artist}/{song} → 直接播放音频文件
GET /health     → 健康检查 + 歌曲数量
GET /list       → 歌曲列表
```

systemd 用户服务管理，开机自启。

## 车机播放方案对比

秦L 搭载比亚迪 DiLink 系统（基于 Android），不原生支持 SMB/NFS：

| 方案 | 原理 | 前提 | 推荐度 |
|------|------|------|--------|
| DLNA 投放 | 车机搜索 DLNA 设备 | 车停家里 + 连 WiFi | ★★★★ |
| 手机中转 | 手机浏览器打开 music-server | 手机和 NAS 同局域网 | ★★★★★ |
| 外网播放 | CF Tunnel 暴露 music-server | 需配置 ingress | ★★★ |
| USB 拷贝 | 手动拷贝 mp3 | 无 | ★★ |

外网播放注意事项：wav/flac 大文件通过 CF Tunnel 免费版传输会很慢（TTFB 1-5s + 带宽限制），建议转码为 mp3 或只暴露 mp3 文件。

## 音乐下载工具链

| 工具 | 安装方式 | 音源 | 特点 |
|------|---------|------|------|
| 网易云下载器 | 纯 Python 标准库 | 网易云音乐 | 轻量、无需第三方依赖 |
| musicdl | pip install musicdl | 网易/QQ/酷狗/酷我/B站 | 多平台、需 nodejs-wheel |
| 音微网 (yinwe.com) | 浏览器提取 audio src | 免费在线听歌站 | 给链接即下载 |

### 音微网下载流程

```bash
# 1. 浏览器打开音微网歌曲页面
# 2. 提取 <audio> 标签的 src URL
browser_console: (() => {
  const a = document.querySelector('audio');
  return a ? a.src : 'no audio found';
})()

# 3. curl 下载到 NAS 音乐目录
curl -sL "https://ftp.tool55.com/xrkjpay/music/xxx.mp3" \
  -o "/volume1/Share/Media/Music/歌手/歌手 - 歌名.mp3"

# 4. music-server 自动识别新文件
curl http://127.0.0.1:8091/health | python3 -c "import sys,json; print(json.load(sys.stdin)['song_count'])"
```

## 避坑提示

- **micli play_by_url 需要完整 URL 编码**：中文路径必须 `urllib.parse.quote()`，否则小爱无法识别
- **musicdl 安装很慢**：依赖 nodejs-wheel-binaries（58MB）+ av（34MB），安装需 12+ 分钟
- **musicdl 会降级 cryptography**：从 50.0.0 降到 46.0.7，可能影响其他包兼容性。建议在独立 venv 中安装
- **小爱音箱 DID**：每台设备有唯一 DID（Device ID），需要在 mi token 中查找。DID=640446840 是小爱 L15A
- **DLNA 和 HTTP 直链的区别**：DLNA 是推送模式（服务器推送内容到播放设备），HTTP 直链是拉取模式（播放设备主动请求）。车机 DiLink 两种都支持
