## Docker 容器网络问题

今天部署服务时遇到 Docker 容器无法访问宿主机的问题。

### 解决方案

1. 使用 host.docker.internal 而不是 localhost
2. 或使用 --network host 模式

### 配置示例

```bash
export DATABASE_URL=postgres://admin:***REDACTED***@localhost:5432/mydb
export API_TOKEN=***REDACTED***
export PASSWORD=***REDACTED***
```

注意：不要把密码硬编码在 Dockerfile 里！
