# B站 biliup 上传陷阱：返回 BV 号但视频实际不存在

## 问题/背景

使用 biliup CLI 工具上传新闻视频到 B 站，上传过程返回了 BV 号（`BV15jbe6hE3p`）和 AV 号，看似成功。但用户访问 B 站链接 `https://www.bilibili.com/video/BV15jbe6hE3p` 时，页面显示"视频不存在"。

## 关键操作

### 诊断过程

1. **检查 B 站 API**：`curl` 请求 B 站视频 API，返回 `-404 啥都木有`
2. **检查 cookie 有效性**：`biliup info` 返回"风控校验失败"
3. **检查 cookie 文件内容**：`DedeUserID` 字段为空

### 根因

cookie 文件已过期或无效。biliup 上传时虽然 HTTP 请求返回了 BV 号，但实际因为 cookie 问题（风控校验失败），视频并没有真正发布成功。biliup 没有对返回结果做有效性校验，直接输出了"成功"信息。

### 修复方案

需要重新扫码登录 B 站获取新 cookie：

```python
# PTY 模式运行 biliup login，选择"扫码登录"
import pty, os, time, select

master, slave = pty.openpty()
pid = os.fork()
if pid == 0:
    os.setsid()
    os.dup2(slave, 0)
    os.dup2(slave, 1)
    os.dup2(slave, 2)
    os.close(master)
    os.execlp("biliup", "biliup", "login")
else:
    os.close(slave)
    # 等待菜单出现，发送选择"扫码登录"
    time.sleep(3)
    os.write(master, b"\x1b[A\n")  # 上箭头 + 回车
    # 等待二维码生成
    time.sleep(5)
    # 读取输出，提取二维码路径
    output = b""
    while select.select([master], [], [], 0.1)[0]:
        output += os.read(master, 4096)
    print(output.decode())
```

### biliup 安装与使用

```bash
# 安装

# 扫码登录（PTY 交互模式）
```

## 经验/坑

### biliup 上传陷阱

| 陷阱 | 原因 | 检查方法 |
|------|------|----------|
| 返回 BV 号但视频不存在 | cookie 过期/风控校验失败 | 用 B 站 API 验证 BV 号是否有效 |
| cookie 过期无警告 | biliup 不校验返回结果 | 上传前用 `biliup info` 检查登录状态 |
| DedeUserID 为空 | 扫码登录时未正确获取 | 检查 `cookies.json` 中 `DedeUserID` 字段 |

### B 站 API 验证视频是否存在

```bash
# 通过 BV 号查询视频信息
curl -s "https://api.bilibili.com/x/web-interface/view?bvid=BV15jbe6hE3p"
# 返回 code=-404 表示视频不存在
# 返回 code=0 表示视频存在
```

### 最佳实践

1. **上传前**：`biliup info` 检查 cookie 是否有效
2. **上传后**：用 B 站 API 验证 BV 号是否真实存在
3. **cookie 保存**：确认 `cookies.json` 中 `DedeUserID` 和 `SESSDATA` 都不为空
4. **定期更新**：B 站 cookie 有有效期，建议每周检查一次
