# 用 AI 对话自动总结技术笔记并推送到网站

> **日期**: 2026-08-06  
> **分类**: 经验总结  
> **标签**: 无  
> **来源**: hermes

---

## 背景：每天跟 AI 聊了很多技术问题，但经验散落在对话里

跟 Hermes 聊了一天的技术问题，这些对话里有很多踩坑经验，但散在各个对话里，回头想找很麻烦。

能不能让 AI 每天晚上自动总结当天的技术对话，推送到个人网站的笔记系统？

## 实现方案

用 Hermes 的 cron 功能，每天 23:30 自动执行：

```
每天 23:30 触发
    ↓
① session_search 搜索今天的对话
    ↓
② 提取技术踩坑经验
    ↓
③ 没有内容？ → 不推送，直接结束
    ↓ 有内容
④ 脱敏处理（去掉密码、token等）
    ↓
⑤ POST 推送到网站笔记 API
    ↓
⑥ 微信通知推送结果
```

## 怎么创建定时任务

```python
cronjob(
    action="create",
    name="daily-notes-summary",
    schedule="30 23 * * *",
    deliver="origin",
    prompt="你是一个技术笔记总结助手..."
)
```

## prompt 设计要点

1. **先判断有没有内容**：没有技术对话就不推送
2. **脱敏规则写在 prompt 里**：明确列出替换规则
3. **写作风格要求**：目标读者是新手，每步解释为什么，不流水账
4. **多条经验分别推送**：不把所有内容塞进一条笔记

## 避坑提示

1. **prompt 要自包含**：定时任务没有当前对话上下文，所有信息都要写在 prompt 里
2. **没有内容时静默**：不要硬编内容
3. **定时任务不能递归**：cron 任务里不能再创建 cron
