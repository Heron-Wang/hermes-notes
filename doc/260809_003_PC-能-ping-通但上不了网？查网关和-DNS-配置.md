# PC 能 ping 通但上不了网？查网关和 DNS 配置

> **日期**: 2026-08-09  
> **分类**: 踩坑记录  
> **标签**: 网络, Windows, 运维, 故障排查  
> **来源**: hermes

---

## 背景/问题

局域网里一台 PC，能 ping 通其他设备，远程桌面也能连，但就是上不了网——浏览器打不开网页，微信连不上。

## 原因分析

"能 ping 通内网但上不了网"通常意味着数据包到了局域网就出不去了。最常见的原因：

### 原因1：网关指向了错误的地址

这是最常见的原因。很多家庭网络有这样的拓扑：

```
互联网 → 软路由/旁路由(如 .104) → 交换机 → 各设备
                                      ↑
  物理路由器(如 .1) 只当交换机/AP 用，不负责拨号出网
```

如果 PC 的静态 IP 配置里网关指向了 `.1`（物理路由器），但物理路由器并不负责路由出网，数据包到了 `.1` 就出不去了。

### 原因2：DNS 配置错误

DNS 写成了无效地址（比如 `4.4.4.4` 而不是 `8.8.8.8`），或者 DNS 指向了不响应的服务器。表现为：ping IP 能通，但用域名访问网页/微信失败。

### 原因3：代理软件残留

之前装过 Clash/V2Ray 等代理软件，即使软件关了，**系统代理设置可能还残留着**（注册表里 `ProxyEnable=1`），导致所有 HTTP 请求都被发往 `127.0.0.1:7897`（代理端口），但代理已经不在跑了，请求全部超时。

## 解决方案

### 第1步：确认网络配置

在 PC 上打开管理员 PowerShell：

```powershell
ipconfig /all
```

重点看：
- **默认网关**：是否指向了正确的路由器地址？
- **DNS 服务器**：是否是有效的 DNS 地址？

常见有效 DNS：
- `223.5.5.5`（阿里 DNS，国内快）
- `8.8.8.8`（Google DNS）
- 软路由的 IP（如果你的软路由支持 DNS 转发）

### 第2步：修复网关和 DNS

```powershell
# 修改网关和 DNS（管理员 PowerShell）
# name 是网卡名称，用 ipconfig /all 里的"以太网适配器"名称
netsh interface ip set address name="以太网" static 192.168.0.99 255.255.255.0 192.168.0.104
netsh interface ip set dns name="以太网" static 223.5.5.5 primary
netsh interface ip add dns name="以太网" 8.8.8.8 index=2

# 验证
ipconfig /all
tracert 223.5.5.5   # 看数据包能到哪一跳
```

### 第3步：检查代理残留

```powershell
# 检查系统代理状态
Get-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" | Select-Object ProxyEnable, ProxyServer

# 如果 ProxyEnable=1 但代理已关，手动清除：
Set-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" -Name ProxyEnable -Value 0

# 检查谁还占着代理端口
Get-Process | Where-Object {$_.Id -in (Get-NetTCPConnection -LocalPort 7897 -ErrorAction SilentlyContinue).OwningProcess} | Select-Object Name, Id, Path
```

### 第4步：重置网络栈（如果以上都正常但还是不行）

```powershell
netsh winsock reset
netsh int ip reset
ipconfig /release
ipconfig /renew
ipconfig /flushdns
```

然后重启电脑。

## 避坑提示

### 怎么快速判断是网关问题还是 DNS 问题

```powershell
# 能 ping 通 IP 但 ping 不通域名 → DNS 问题
ping 223.5.5.5      # 通
nslookup baidu.com  # 失败

# IP 都 ping 不通 → 网关问题
ping 223.5.5.5      # 超时
tracert 223.5.5.5   # 第一跳就超时
```

### 从另一台机器远程诊断

如果你有另一台能上网的机器（比如 NAS），可以通过 ARP 表和端口扫描确认目标 PC 的状态：

```bash
# 查看 PC 是否在线（ARP 表状态）
ip neigh show | grep 192.168.0.99
# REACHABLE = 在线，STALE = 之前在线但很久没通信

# 扫描 PC 的端口确认服务状态
python3 -c "
import socket
for p in [3389, 445, 139, 80]:
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(2)
    try:
        s.connect(('192.168.0.99', p))
        print(f'端口 {p}: 开放')
        s.close()
    except:
        print(f'端口 {p}: 不通')
"
```

### 代理软件自启问题

Clash/V2Ray 等代理软件会在多个地方藏自启：
- 注册表 `HKCU:\Software\Microsoft\Windows\CurrentVersion\Run`
- 计划任务
- Windows 服务

彻底禁用：
```powershell
# 查注册表自启项
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run"

# 查计划任务
Get-ScheduledTask | Where-Object {$_.TaskName -like '*clash*' -or $_.TaskName -like '*v2ray*'}

# 查服务
Get-Service | Where-Object {$_.DisplayName -like '*clash*' -or $_.DisplayName -like '*v2ray*'}
```
